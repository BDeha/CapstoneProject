# Privilege Walk Polling Application

An interactive classroom polling web application built with a **React** frontend, **Node.js / Express** backend, and **MySQL** database for real-time local-network deployment.

## Project Structure

```text
CapstoneProject/

    ├── privilege-frontend/   # React client application
    ├── capstone table.sql    # MySQL database schema

    └── stop_walk.bat         # Windows shutdown script
